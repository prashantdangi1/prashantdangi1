### What I do

Sit in the customer's repo. Scope a shippable slice. Prototype in Python. Integrate with their APIs, auth, and CI/CD. Hand over working software, not a slide deck.

Recently:

- **Scaler 3.0** — embedded with DevOps; shipped backend features and LLM-integrated services used by thousands of learners
- **Internal AI lab platform** — model routing, caching, async batch generation; ~20% lower per-unit cost, now in daily production
- **20+ client teams** — web, API, and cloud (AWS/Azure); auth, backends, and CI/CD gates shipped inside *their* pipelines

### How I work
